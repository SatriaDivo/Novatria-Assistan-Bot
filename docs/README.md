# Dokumentasi Novatria-Bot

Selamat datang di direktori Dokumentasi **Novatria Assistant Bot**. Direktori ini berisi spesifikasi lengkap yang memandu tujuan bisnis dan panduan implementasi perangkat lunak untuk bot.

## Direktori Dokumen

- **[BRD (Business Requirements Document)](BRD.md)**: Berfokus pada aspek bisnis, latar belakang masalah, tujuan pengembangan, ruang lingkup, dan daftar pemangku kepentingan (stakeholders).
- **[SRS (Software Requirements Specification)](SRS.md)**: Berfokus pada spesifikasi teknis, detail fungsional dari setiap command, arsitektur integrasi, struktur database, dan kebutuhan non-fungsional sistem.

## Cara Menggunakan Dokumen Ini
Dokumen ini disusun menggunakan format Markdown. Mulailah dengan membaca `BRD.md` untuk memahami konteks dan tujuan utama sistem, lalu lanjutkan ke `SRS.md` untuk melihat rincian spesifikasi teknis dari fitur-fitur seperti Sinkronisasi Google Sheets, Tracking CTF, dan Integrasi GitHub.
