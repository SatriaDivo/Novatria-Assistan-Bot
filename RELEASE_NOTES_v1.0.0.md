# v1.0.0 - Novatria Assistant Initial Stable Release

Initial stable release for Novatria Assistant.

## Added

- Slash commands for `/ping`, `/help`, `/status`, `/catat`, `/todo`, `/link`, `/jadwal`, `/arsip`, `/list`, and `/hapus`.
- Google Sheet integration.
- Google Calendar integration.
- Auto-log activity to the configured Discord log channel.
- Docker support for local deployment.
- GitHub Actions CI.
- Prettier formatting setup.
- MIT License.

## Notes

- Secrets remain outside the repository through `.env`.
- `google-apps-script.local.js` remains local-only and is ignored by Git.
